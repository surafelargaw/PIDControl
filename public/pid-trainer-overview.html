HOW THE APP WORKS / 02

A repeatable operator learning cycle

The app connects instruction, simulation, and feedback in four practical steps.

Operators can move from a control concept to a simulated operating decision, observe the process response, and review objective performance measures—all without modifying a production system.

01 / LEARN

Understand the control concept

Use searchable lessons, diagrams, field definitions, and interactive examples to understand loop signals and PID terms.

02 / CONFIGURE

Set up the operating case

Select a process or HVAC plant, then configure controller gains, modes, limits, filters, disturbances, and equipment effects.

03 / SIMULATE

Observe cause and effect

Run, pause, accelerate, or step the simulation while synchronized trends show SP, PV, output, and PID contribution changes.

04 / EVALUATE

Review the result

Use stability classification, overshoot, settling time, error metrics, diagnostics, scenario scores, and saved comparisons.

Practice the decisions operators make on data-center cooling systems.

The HVAC workspace connects PID behavior to recognizable operating conditions: supply temperature, pressure, room temperature, outdoor conditions, IT load, equipment position, alarms, and cooling constraints.

PRACTICE & EVIDENCE / 07

Training delivery and oversight

Support individual practice while giving leadership a consistent training structure.

A common workflow, defined scenarios, objective scoring, and saved attempts make PID development more repeatable than informal trial-and-error training.

01Select

Choose a process model, HVAC template, vendor profile, imported dataset, or defined scenario.

02Configure

Set the controller algorithm, gains, modes, limits, filters, plant options, and disturbance conditions.

03Execute

Run, pause, step, accelerate, apply disturbances, and inspect the response with trend cursors.

04Evaluate

Review stability, overshoot, settling, error indices, oscillation, saturation, and actuator activity.

05Document

Save the run locally, compare attempts, and export CSV data or a PDF summary.

MEASURABLE ASSESSMENT

Defined performance criteria

Scenario scores use measures such as overshoot, settling, error, alarms, saturation, and actuator activity—not completion alone.

LOCAL TRAINING OVERSIGHT

Attempts and progress visibility

Instructor and leaderboard views summarize locally stored attempts, pass rates, and comparative scenario performance.

LOW-INFRASTRUCTURE DEPLOYMENT

Client-side architecture

No application backend is required. Runs and attempts remain in browser storage, and a service worker supports offline use.

THE VALUE / 08

Expected impact

Benefits for operators—and for the organization supporting them.

✓Operator understanding: connect PID settings to visible process and equipment behavior.
✓Safer practice: test controller changes and fault responses without affecting production equipment.
✓Consistent diagnosis: distinguish tuning issues from sensor, actuator, load, and equipment limitations.
✓Faster knowledge transfer: provide one training environment for different roles, process types, and BAS conventions.
✓Measurable development: use defined scenarios, scores, saved attempts, and performance metrics to review progress.
✓Standardized discussion: establish common terms for stability, overshoot, settling, saturation, and oscillation.
The platform supports education, comparative analysis, and pre-field practice. Production changes remain subject to site validation, operating limits, safety review, and approved change-control procedures.
